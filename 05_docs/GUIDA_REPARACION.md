# Custom ROM — Realme Narzo 20 (RMX2193EEA)

Reparación de boot loop Orange State en Realme Narzo 20 con firmware C.18.

## Contenido

| Carpeta | Descripción |
|---------|-------------|
| `solicitudes/` | **Paquete completo para réplica** — incluye todo lo necesario |
| `GUIA_REPARACION_ORANGE_STATE.md` | Guía paso a paso para usuarios |
| `scripts/` | Scripts Python probados |

| `01_firmware/` | Firmware C.18 extraído |

## Empezar aquí

1. Leer `solicitudes/README.md`
2. Instalar drivers → `solicitudes/drivers/MTK_VCOM_Drivers_README.md`
3. Seguir `GUIA_REPARACION_ORANGE_STATE.md`
4. Usar `solicitudes/CHECKLIST_REPARACION.md` para marcar progreso
